# Another FNAF Fangame: Reopening Source — Godot

> Source code only. Original game assets and audio are not included. You'll need to provide them yourself.

Исходный код Godot-проекта: игровая логика на GDScript, текстовые сцены и шейдеры.
Графика, музыка, звуки, озвучка, шрифты и иконка проекта распространяются отдельно
и в этот репозиторий не входят.

## Состав

| Путь | Содержимое |
| --- | --- |
| `project.godot` | Настройки проекта и стартовая сцена |
| `scripts/` | Игровая логика, интерфейс, AI, локализация и замер производительности |
| `scenes/` | Текстовые сцены Godot (`.tscn`) |
| `shaders/` | Исходники шейдеров |
| `tools/export_source.py` | Создание архива только с исходниками |

Файлы `.gd.uid` и `.gdshader.uid` сохраняют идентификаторы исходных ресурсов.
Кэш `.godot/`, файлы импорта `.import`, настройки экспорта, сборки, логи и
локальные рабочие заметки исключены.

## Лицензия

Лицензия на исходный код пока не указана. Публикация исходников сама по себе
не предоставляет разрешения на их доработку и распространение. См.
[пояснение GitHub о лицензировании](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).
Указания авторства сохранены в коде и в игровых кредитах. Условия использования
исходных компонентов нужно уточнить у их правообладателей до выбора общей лицензии.

## Запуск с собственным комплектом ресурсов

В `project.godot` указана версия Godot **4.7**, рендерер **Forward Plus**.
Полноценный запуск игры требует отсутствующих в репозитории ресурсов:

1. Восстановите каталог `assets/` из имеющейся у вас локальной копии, сохранив
   имена файлов и структуру: `fonts/`, `gm/`, `sprites/`, `sounds/`, `phone_guy/`
   и `minigames/`. Код загружает ресурсы по путям `res://assets/...`.
2. Поместите иконку в `icon.svg` в корне проекта либо выберите свою в настройках
   проекта Godot.
3. Откройте `project.godot` в редакторе, дождитесь импорта и запустите проект
   клавишей F6 для текущей сцены или F5 для игры.

Без этих ресурсов код можно изучать и редактировать, но полноценная игра
не запустится. Кэш импорта Godot создаст автоматически. Настройки экспорта
для нужной платформы создайте локально через **Project → Export**.

## Подготовка исходников для GitHub

Из корня локального проекта выполните (нужен Python 3.9 или новее):

```bash
python3 tools/export_source.py --check
python3 tools/export_source.py
```

Архив появится в `dist/AFFRS-GODOT-source.zip`. В него входят только разрешённые
исходники, конфигурация проекта и документация. Скрипт проверяет текстовый формат,
отсутствие символических ссылок и соответствие UID исходным файлам. Локальные
ассеты и другие исключённые файлы остаются на месте.

Распакуйте архив в отдельную папку. Для нового репозитория в этой папке:

```bash
git init -b main
git add .
git diff --cached --stat
git diff --cached --name-only
git commit -m "Initial source release"
```

Затем подключите созданный на GitHub пустой репозиторий и отправьте ветку `main`.
Файл `.gitignore` использует список разрешений: новые типы исходников и документы
нужно явно добавлять в него и в `tools/export_source.py`.

Если вы публикуете существующий Git-репозиторий, `.gitignore` не удаляет уже
отслеживаемые файлы или старые коммиты. Для первой публикации без прежней истории
используйте отдельную папку из архива по инструкции выше.

Замеры производительности описаны в [scripts/perf/README.md](scripts/perf/README.md).
